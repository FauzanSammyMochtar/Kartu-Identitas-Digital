# Kartu Identitas Digital

## Deskripsi
Proyek yang sungguh sederhana

## Prasyarat
* C Compiler (Seperti GCC/Clang)

## Cara menggunakan
1. Unduh atau clone repositori ini:
git clone https://github.com/FauzanSammyMochtar/Kartu-Identitas-Digital.git

2. Masuk ke folder proyek:
cd Kartu-Identitas-Digital

3. Compile program:
clang kartu_identitas_digital.c -o kartu_identitas_digital

4. Jalankan program:
./kartu_identitas_digital
